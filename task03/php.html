PHP est un langage de programmation libre, principalement utilisé pour produire des pages Web dynamiques via un serveur HTTP, mais pouvant également fonctionner comme n'importe quel langage interprété de façon locale.
  • PHP est intéressant pour créer des pages Web dynamiques.
  • J'apprécie PHP parce qu'il peut être intégré directement dans le HTML.
  • La syntaxe de PHP est assez simple à comprendre lorsqu'on connaît déjà un autre langage de programmation.
  • PHP est particulièrement utile pour développer des applications Web côté serveur.
